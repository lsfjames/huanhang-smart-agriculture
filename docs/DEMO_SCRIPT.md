# 项目演示脚本（3–5 分钟）/ Demo Script

**前提**：本地已启动前端 + Gateway + user/diagnosis + vision/language（私有仓 `docs/environment` 说明）。  
**声明**：演示数据为样本，不承诺田间效果。

| 时间 | 画面 | 口述要点 |
| --- | --- | --- |
| 0:00–0:20 | 打开系统登录页 | 本地优先全栈；角色：农户/专家/管理员 |
| 0:20–0:50 | 农户登录 → 地块列表 | 业务闭环起点 |
| 0:50–1:30 | 上传叶片图 → 分类结果 + 检测框 | MobileNet 三分 + YOLO 框；**标签体系不同** |
| 1:30–2:10 | 农技问答：症状问题 → 证据卡 | hybrid RAG + 图路径 |
| 2:10–2:30 | 超范围问题 → 如实拒答 | 不编造剂量/预测 |
| 2:30–3:00 | 专家工作台 → 提交复核 | 跨农户队列与权限 |
| 3:00–3:30 | 管理台：用户角色 / 模型版本 / 知识审核 | 文件元数据 sha256；知识审核写库/文件 |
| 3:30–4:00 | 巡检回放：批量导入时间线 | **Offline Replay** 非无人机 |
| 4:00–4:30 | 架构图 + 限制说明 | mAP 0.074、Docker/CI 未实测 |
